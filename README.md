# Turawa Trust Foundation

A transparent blockchain-based donation platform built on Cardano.

## About

Turawa Trust Foundation restores trust in charitable giving through blockchain transparency. Every donation is recorded on the Cardano blockchain, ensuring complete accountability and traceability.

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Cardano Blockchain (via Mesh SDK)

## Getting Started

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Features

- **Transparent Donations**: All donations recorded on-chain
- **Real-time Tracking**: Monitor fund distribution in real-time
- **Proof of Impact**: Upload verification images for distributions
- **Wallet Integration**: Connect Cardano wallets seamlessly
